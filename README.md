# 午前1時の大脱走 オンライン（スマホ対戦版）

ボードゲーム「午前1時の大脱走（1 A.M. Jailbreak / Saashi）」を、スマホのブラウザで2〜5人オンライン対戦できるWebアプリです。
アプリのインストールは不要です。URLを開いて部屋コードを共有するだけで遊べます。

## 遊び方

1. 1人目が名前を入れて「部屋をつくる」→ 4文字の部屋コードが表示される
2. 「招待リンクを共有」でLINEなどに送る（またはコードを伝える）
3. 友達はリンクを開くか、コードを入れて「参加」
4. ホストが設定を確認して「ゲーム開始」

- 手札のカードをタップで選択 →「出す」/「場に付け足す」/「パス」
- 出した後はディスプレイのカードをタップ →「取る」
- 通信が切れたりページを再読み込みしても、同じ端末なら自動で復帰します

## 起動方法（ローカル）

```bash
npm install
npm start          # http://localhost:3000
npm test           # ロジックの自動テスト（600ゲーム）+ 通信テスト
```

同じWi-Fiのスマホからは `http://<PCのIPアドレス>:3000` で接続できます。

## インターネットに公開する（例：Render の無料プラン）

1. このフォルダをGitHubリポジトリにpush
2. https://render.com で「New → Web Service」→ リポジトリを選択
3. Build Command: `npm install` / Start Command: `npm start`
4. 発行された `https://xxxx.onrender.com` をスマホで開く

WebSocketが使えるNode.jsホスティングなら同様に動きます（Railway、Fly.io、VPSなど）。
環境変数 `PORT` に対応しています。
※ 部屋の情報はサーバーのメモリ上にあるため、サーバーが再起動すると進行中のゲームは消えます。無料プランは放置でスリープするので、最初のアクセスは少し時間がかかります。

## 実装したルール

| 項目 | 内容 |
|---|---|
| カード | 数字1〜8 各6枚 ＋ オールマイティ(★) 4枚 ＝ 52枚 |
| ラウンド | 3ラウンド（設定で変更可） |
| 配り枚数 | 2人:10枚 / 3人:10枚 / 4人:9枚 / 5人:8枚（設定で変更可） |
| ディスプレイ | 山札から5枚を公開。取られたら山札から補充 |
| リード | 場が空なら手札から1〜3枚をラン（連番）かセット（同じ数字）で出す |
| フォロー | まず場札に手札から1枚付け足してよい（ラン/セットを崩さない）。その後、直前の場札と同じ枚数か±1枚をラン/セットで出す。数字の大小は無関係 |
| 補充 | 出した後、ディスプレイから1〜2枚を手札へ（出し切ったときは不要） |
| パス | 場札を流し、次のプレイヤーが自由に1〜3枚出す |
| 和了り | 手札を出し切ったら脱走成功 |
| ラウンド終了 | 「人数−1」人が和了ったら終了（設定で変更可） |
| 得点 | 残った手札1枚につき−1点（「数字の合計」方式も選択可） |
| 勝利 | 全ラウンド合計のマイナス点が最も少ない人 |

### 参考記事に記載がなく、仮に決めた点

参考記事（note）はレビュー記事のため、以下は推定で実装しています。正式ルールと違う場合は、ロビーの設定か `game.js` の `defaultSettings()` で変更してください。

- カードの枚数構成、人数ごとの配り枚数
- ラウンド終了となる和了り人数（既定：人数−1人）
- 得点方式（既定：残り1枚=1点）
- パスしたときにディスプレイから取るか（既定：取らない）
- 「±1枚」の基準は付け足し後の場札の枚数
- 付け足しで手札が0枚になった場合も和了り
- 各ラウンドの最初の手番は1人ずつずれていく

## ファイル構成

```
server.js        HTTP + WebSocket サーバー（部屋管理・再接続）
game.js          ゲーム進行ロジック（手札は本人にだけ送信）
public/rules.js  ラン/セット判定（サーバーとブラウザで共通）
public/index.html, app.js, style.css  スマホ向け画面
test/            自動テスト
```
